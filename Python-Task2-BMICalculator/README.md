# BMI Calculator using Python

A simple Python-based BMI (Body Mass Index) Calculator that calculates a user's BMI based on their height and weight, then displays the corresponding health category. The program also validates user input to ensure accurate results.

---

## ✨ Features

- Calculates Body Mass Index (BMI)
- Classifies BMI into health categories
- Validates user input
- Automatically converts height from centimeters to meters (if needed)
- Allows multiple BMI calculations in one session

---

##  Technologies Used

- Python 3
- Functions
- Conditional Statements
- Loops
- Exception Handling

---

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/BMI-Calculator.git
```

Move to the project folder:

```bash
cd BMI-Calculator
```

Run the program:

```bash
python bmi_calculator.py
```

---

##  BMI Categories

| BMI Range | Category |
|-----------|----------|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal |
| 25.0 – 29.9 | Overweight |
| 30.0 and above | Obese |

```
=== BMI Calculator ===
```
